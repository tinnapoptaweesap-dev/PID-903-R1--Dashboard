# รายงานความก้าวหน้าโครงการ — สัญญา PID-903(R1)

เว็บไซต์แบบ Static (HTML/CSS/JS ล้วน) สำหรับนำเสนอความก้าวหน้างานวางท่อจ่ายน้ำ
สัญญา PID-903(R1) (ถนนปานวิถี จ.สมุทรปราการ · กม.0+000–3+665) ต่อคณะกรรมการตรวจรับพัสดุ

ออกแบบตามแม่แบบ รทป.186 แต่ **ปรับสถาปัตยกรรมข้อมูลให้เป็นแบบ chainage** (งานวางท่อขุดเปิด)
ไม่ใช่แบบบ่อพัก/ดันท่อ:
- Signature visual = **แถบแนวสาย (Chainage Route Strip)** แบ่งช่วงตามวิธีก่อสร้าง (ในคูน้ำ / ข้ามคลอง / ไหล่ทาง)
- หน่วยความก้าวหน้าหลัก = **ระยะท่อที่วางได้ (เมตร)** เทียบแนวสาย 3,665 ม.
- แท็บที่ 3 = **รายช่วงงาน (S1–S5)** แทนรายบ่อพัก

## โครงสร้างไฟล์

```
PID903R1-dashboard/
├── index.html   หน้าเว็บหลัก (3 แท็บ: ภาพรวม / รายงานรายวัน / รายช่วงงาน)
├── style.css    ธีม MWA "Engineering Blueprint" (สีองค์กร กปน.)
├── data.js      ข้อมูลทั้งหมด (แก้ผ่านสคริปต์เท่านั้น)
├── app.js       ตรรกะการแสดงผล + Chainage Route Strip
└── tools/
    ├── pid903.py            เครื่องมือหลัก (inspect / patch / verify)
    ├── delta_template.json  แม่แบบกรอกใบรายงาน 1 ฉบับ
    └── delta/               เก็บ delta-YYYY-MM-DD.json ทุกรอบ (audit trail)
```

## รอบการทำงานเมื่อได้ใบรายงานประจำวัน

```bash
# 1) กรอกข้อมูลใบรายงานลง delta (คัดลอกจาก delta_template.json)
#    - segs อ้าง id ช่วงงาน S1..S5 ; meters = ระยะท่อที่วางได้ (ม.)
# 2) ผสานเข้า data.js
python3 tools/pid903.py patch --file data.js \
        --delta tools/delta/delta-2569-07-31.json \
        --out data.new.js --gen 2569-07-31 --rev 1
# 3) อ่าน digest + ตรวจ QA แล้วนำ data.new.js ทับ data.js เมื่อถูกต้อง
python3 tools/pid903.py verify --file data.new.js
```

- `patch` จะ upsert ตาม `iso`, กัน record ซ้ำ, คำนวณระยะที่วาง, ตรวจช่องว่างปฏิทิน และ `node` eval ยืนยัน syntax อัตโนมัติ
- แผน/ผลงานจริง S-Curve (`scurve.planMonthly` / `actualMonthly`) ต้อง **cross-check กับ ปร.5/ปร.6 / งวดงาน** ก่อนป้อน

## รายการที่ต้องยืนยัน (Verify Before Use) — แสดงบนแบนเนอร์เหลืองในหน้าเว็บด้วย

1. **มูลค่าสัญญา 19,520,000 บาท** และ **หลักประกันสัญญา 971,000 บาท** — cross-check กับคู่ฉบับสัญญา
2. **ปริมาณท่อรายชนิด (Pipe Schedule)** — cross-check กับ BOQ ต้นฉบับ
3. **จุดแบ่งช่วง Chainage** (breakpoints ใน `data.js` → `alignment.bands`) — ยืนยันด้วยแบบ 600 DPI/ภาคสนาม
4. **ผลต่างความยาวแนวสาย 3,665 ม. กับผลรวม Pipe Schedule 4,146 ม.** — ยัง resolve ไม่เสร็จ
5. **แผนงานหลัก S-Curve** — รอป้อนจากตารางแผนงาน/งวดงานที่อนุมัติ
