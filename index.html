1 ข้อมูลโครงการและคู่สัญญา

ผู้ว่าจ้าง: การประปานครหลวง (กปน.) — เจ้าของสัญญาแต่เพียงผู้เดียว (คู่สัญญาเดียว)

ผู้รับจ้าง: บจก. ไทคูนวณิชย์ — ผู้ดำเนินงานก่อสร้าง

วัสดุ: ผู้รับจ้างจัดหาเองทั้งหมด ไม่มีท่อ/อุปกรณ์ที่ กปน. จัดให้

บทบาทหน่วยงานภายนอก (มิใช่คู่สัญญา): กรมชลประทาน / อบต.คลองด่าน / แขวงทางหลวงสมุทรปราการ เป็นเจ้าของพื้นที่และผู้ออกใบอนุญาต ที่ กปน. ต้องขออนุญาตเข้าก่อสร้างเท่านั้น — ไม่มีความสัมพันธ์ทางสัญญากับผู้รับจ้าง

3 กรอบเวลาและการรับประกันผลงาน

ลงนามสัญญา 10 เม.ย. 69 → แจ้งเริ่มงาน (NTP) 27 ก.ค. 69 → ประชุมก่อนเริ่มงาน 7 ส.ค. 69 → ครบ 210 วัน ส่งมอบงาน 22 ก.พ. 70 → รับประกันผลงาน +2 ปี

ข้อสังเกตเชิงบริหารเวลา: เวลาสัญญาเริ่มเดินตั้งแต่ 28 ก.ค. 69 — ณ วันประชุม 7 ส.ค. 69 ใช้เวลาสัญญาไปแล้วประมาณ 10–11 วัน จึงควรเร่งรัดการส่งเอกสารขออนุมัติ/แผนงานให้ทันโดยไม่รบกวน Critical Path

แผนงานสะสม (S-Curve): 3% → 13% → 33% → 58% → 80% → 95% → 100% (ก.พ. 70) — เดือน ต.ค.–พ.ย. เป็นช่วงเนื้องานเข้มข้นที่สุด (รวม 47% ของสัญญา) ตรงกับช่วงหลังงานข้ามคลอง Critical Path

4 เส้นทางวิกฤต (Critical Path) และใบอนุญาตเข้าพื้นที่

จุดข้ามคลองกันยา (กม. 2+912–2+950): ท่อเหล็กเหนียว ST ϕ300 ยาว ~46 ม. วางบนโครง truss (ปรับจากโครงสร้าง A-frame เดิม เนื่องจากขยาย span เพื่อเปิดช่องเดินเรือ)

✓ ใบอนุญาตทั้งสองฉบับ (อบต.คลองด่าน เลขที่ 2/2569, แขวงทางหลวงสมุทรปราการ คค 2735/... ) ได้มาก่อน NTP แล้ว จึงไม่มีความเสี่ยงด้านเอกสารเข้าพื้นที่คงค้าง

สาเหตุที่เป็น Critical Path: การเปลี่ยนรูปแบบโครงสร้างรับท่อ (A-frame → truss) ทำให้เกิดรอบแก้ไขแบบ/ขออนุมัติเพิ่มเติม และงานยกติดตั้งด้วย mobile crane ที่ต้องวางแผนละเอียด — ควรเร่งรัดการอนุมัติแบบ truss และวางแผนงานเครนล่วงหน้า
